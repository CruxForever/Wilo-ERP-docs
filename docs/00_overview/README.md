# Что такое Wilo-ERP

Wilo-ERP — рабочий инструмент финансового контролёра завода Wilo Rus.
Система собирает данные из разных источников, рассчитывает себестоимость и формирует управленческую отчётность.

---

## Зачем нужна эта система

Задача контролёра — каждый месяц собирать данные из 1С, Excel и SAP, сводить их воедино и отправлять отчёты в HQ.

Без Wilo-ERP это делается вручную: десятки Excel-файлов, ручной перенос цифр, высокий риск ошибки.
С Wilo-ERP — единый инструмент с понятной логикой: загрузил данные, запустил расчёт, получил отчёт.

---

## Что умеет система

| Задача | Как это выглядит |
|--------|-----------------|
| Загрузка данных | Выгружаете файл из 1С или Excel, система разбирает и проверяет его |
| Расчёт себестоимости | Задаёте объёмы — система раскрывает спецификации (BOM) и считает материальные затраты |
| Расчёт тарифов | Система считает ставки прямого труда и накладных расходов по подразделениям |
| Распределение затрат | По настроенным правилам переносит затраты между подразделениями |
| Формирование отчётов | Выгружает готовые Excel-файлы: MFC Report, план-факт, себестоимость по SKU |

---

## Как выглядит работа с системой

Типичный ежемесячный цикл:

```mermaid
flowchart LR
    A["1. Выгрузка\nданных из 1С"] --> B["2. Загрузка\nв Wilo-ERP"]
    B --> C["3. Расчёты\n(тарифы, BOM, переносы)"]
    C --> D["4. Проверка\nрезультатов"]
    D --> E["5. Excel-отчёты\n→ HQ"]
```

Пошаговые инструкции для каждого процесса — в разделе **[Runbooks](../40_runbooks/run_reporting.md)**.

---

## Откуда берутся данные

- **1С** — фактические затраты (OPEX), остатки запасов, объёмы производства
- **Excel** — спецификации (BOM), маршруты, плановые цены, данные по персоналу
- **SAP / Excel** — данные для отдельных отчётов (KE30, KSB1)
